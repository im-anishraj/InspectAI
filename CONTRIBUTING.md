# Contributing to InspectAI

First off, thank you for considering contributing to InspectAI! It's people like you that make InspectAI such a great tool for the community.

## 🚀 How to Contribute

### 1. Find an Issue
Look through our GitHub Issues for something you'd like to work on. 
- **Beginners:** Look for issues labeled `good first issue` or `help wanted`.
- **Advanced:** Look for `enhancement` or `core-architecture` labels.

### 2. Local Setup
InspectAI consists of two parts: the Chrome Extension and the VS Code Companion.

**Chrome Extension:**
1. Navigate to `/extension`
2. Run `npm install`
3. Run `npm run build`
4. Load the `/extension/dist` folder as an unpacked extension in Chrome.

**VS Code Companion:**
1. Navigate to `/ide-extension`
2. Run `npm install`
3. Press `F5` in VS Code to launch the Extension Development Host.

### 3. Make your Changes
Create a new branch for your feature (`git checkout -b feature/amazing-feature`). Make sure your code is clean and tested locally!

### 4. Submit a Pull Request
Submit a PR using our Pull Request Template. A maintainer will review your code as soon as possible!

## 💡 What can I contribute?
- **Framework Support:** Help us add support for Vue, Svelte, or Angular!
- **IDE Support:** Build companions for JetBrains, Cursor, or Neovim!
- **UI Polish:** Make the onboarding and Chrome extension UI even better.
- **Bug Fixes:** Find and squash bugs.

Thank you for helping us build the ultimate vibe coding tool!
